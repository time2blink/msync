## Решения инженерного ревью (plan-eng-review, 2026-11-15)
- [x] D1: структура кода — ES-модули с import. Код лежит в `js/core` (данные, облако, шифрование) и `js/ui` (экраны). Открывать только через локальный сервер (`python -m http.server` в папке MSync, затем http://localhost:8000) или GitHub Pages.
- [x] D2: слияние — каждая правка получает метку (время + имя компьютера). Метка не бывает меньше уже виденной, поэтому отстающие часы не теряют правки. Внедрено в `js/core/store.js`.
- [x] D3: в каждом файле есть поле версии формата (`v: 2`). Старый формат переводится при чтении, файл новой версии не перезаписывается. Внедрено в `js/core/store.js` и `js/core/sync.js`.
- [x] Тесты в `tests/`, запуск `npm test` (поднимает приложение сам). Четыре набора, все проверки проходят.
- [~] История версий: записи и откат внедрены в `js/core/history.js` (последние 50 на элемент, одна запись на 2 минуты), проверено `test6.js`. История спейсов синхронизируется через GitHub (файлы history/<спейс>.json), проверено test7.js. Сейф пока хранит историю только на этом компьютере. Ещё не сделано: экран истории в интерфейсе (после объединения ветки ui).
- [x] Рекомендация по токену: хранить в браузере, токен только на один репозиторий и на 90 дней. Текущая реализация так и работает, ничего не менялось.
