# MSync

Личный блокнот с задачами, заметками и журналом выполненного. Работает в браузере на Windows, Mac и телефоне. Данные синхронизируются через приватный репозиторий GitHub.

## Запуск

- **Онлайн:** https://time2blink.github.io/msync/
- **Локально:** в папке проекта выполните `python -m http.server` и откройте http://localhost:8000. Двойной клик по `index.html` не работает: приложение использует модули ES.

## Что умеет

- **Спейсы** (работы) с цветом, у каждого свои списки, задачи и заметки.
- **Задачи:** срок, шаги, заметка, закрепление, повтор (каждый день или неделю), статус на доске.
- **Экраны:** «Сегодня» по всем работам, «Доска», «Теги», «Календарь», «Сделано» (журнал с отчётом в `.md`).
- **Теги** `#слово` и вложенные `#сервер/доступы`.
- **Заметки** с режимом чтения, оглавлением, ссылками `[[название]]` и обратными ссылками, картинками.
- **Нерабочие дни:** отметка в календаре, импорт списка вида `15.10.2027 выход`, выгрузка в файл `.ics`.
- **Версии:** история правок задач и заметок с возвратом к прошлой версии.
- **Сейф:** зашифрованный блок (AES-256-GCM, ключ из мастер-пароля, PBKDF2). Пароль не хранится нигде, восстановить его нельзя.
- **Учёт времени** по работам.
- **Шаблоны списков**, ежедневные копии на этом компьютере (7 дней).
- **Работа без сети** после первой загрузки.

## Текст заметок: что поддерживается

Заметки пишутся в Markdown. Панель над текстом вставляет нужную разметку, в режиме «Читать» она превращается в оформление.

Поддерживается:
- заголовки `#`, `##`, `###`;
- списки `- пункт` и чек-боксы `- [ ]` / `- [x]`;
- **жирный** `**текст**`, `код` в обратных кавычках, блоки кода в тройных кавычках;
- ссылки `[текст](https://...)` и голые адреса `https://...`;
- ссылки на заметки `[[название]]`;
- картинки, вставленные через кнопку «Картинка» (ссылка вида `img:<id>`).

**HTML-теги не поддерживаются.** Всё, что похоже на HTML, например `<b>`, `<script>`, отображается как обычный текст.

### Экранирование

Перед разбором текст экранируется: символы `&`, `<`, `>` и `"` заменяются на безопасные сущности. Поэтому введённый HTML не выполняется и не вставляется в страницу. Ссылки создаются только для адресов `http://` и `https://`, адреса вида `javascript:` не превращаются в ссылки. Проверяется тестом `tests/test10.js`.

## Структура

```
index.html          точка входа
styles.css          оформление
sw.js               кэш для работы без сети
js/core/            данные: store, sync (GitHub), crypto (сейф), history (версии),
                    features (теги, Markdown, повторы и т.д.), days, images, time
js/ui/app.js        экраны и окна
scripts/remind.mjs  напоминания в Telegram (запускаются на GitHub)
tests/              автоматические проверки: npm test (нужен Chrome)
```

## Синхронизация и данные

- Данные спейсов лежат в приватном репозитории в папке `spaces/`, история в `history/`, сейф в `vault.json` (зашифрован), картинки в `images/`.
- Синхронизация не чаще одного раза в минуту.
- Для синхронизации нужен токен GitHub с доступом только к своему приватному репозиторию (право Contents: Read and write). Токен хранится в браузере.

## Напоминания в Telegram

Скрипт `scripts/remind.mjs` каждый день присылает задачи со сроком сегодня и просроченные. Сейф в напоминания не попадает. Чтобы включить, нужно задать секреты в настройках репозитория: `DATA_TOKEN`, `TG_TOKEN`, `TG_CHAT_ID`, и переменные `DATA_REPO`, `TZ_NAME`.
